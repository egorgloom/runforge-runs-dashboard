# Runforge — Runs Dashboard (Тестовое задание)

**Живое демо:** [https://runforge-runs-dashboard-swart.vercel.app](https://runforge-runs-dashboard-swart.vercel.app)

Интерфейс для просмотра запусков AI-агентов. Разработан в рамках тестового задания на позицию **Junior Frontend Developer**.

## 🚀 Стек технологий

- **React 19** + **TypeScript**
- **Vite** (сборщик)
- **CSS Modules** (стилизация без внешних UI-библиотек)
- **Vitest** + **React Testing Library** (тестирование)

## 📦 Установка и запуск

```bash
# 1. Установка зависимостей
npm install

# 2. Запуск в режиме разработки (http://localhost:5173)
npm run dev

# 3. Запуск тестов
npm run test:run

# 4. Сборка production-версии
npm run build
```

## 🧪 Тестирование

Написаны **7 интеграционных тестов**, покрывающих основные пользовательские сценарии и граничные случаи:

- Фильтрация запусков по статусу.
- Поиск по названию и репозиторию.
- Открытие выдвижной панели (drawer) с деталями успешного запуска.
- Сброс фильтров и поиска из пустого состояния.
- Игнорирование невалидного параметра статуса в URL (`?status=...`).
- Отображение стилизации ошибки в деталях упавшего запуска (`failed`).
- Восстановление активных фильтров и поиска из URL при инициализации страницы.

> **Примечание:** Для ручной проверки состояния ошибки добавьте параметр `?fail=1` к URL (например: `http://localhost:5173/?fail=1`).

## 📁 Структура проекта

Проект разделен по логическим слоям (гибридный Feature-Sliced подход для удобства масштабирования):

```text
src/
├── api/          # Слой работы с данными (mock-сервис с задержкой)
│   └── mockRunsApi.ts
├── model/        # Бизнес-логика и типы
│   ├── types.ts  # Типы (Run, RunStatus, и т.д.)
│   └── useRuns.ts# Кастомный хук (загрузка, поиск, фильтры, сортировка, URL)
├── shared/       # Переиспользуемые элементы
│   ├── lib/      # Утилиты (форматирование даты и длительности)
│   └── ui/       # Универсальные состояния (Skeleton, ErrorState, EmptyState)
├── components/   # Специфичные компоненты страницы
│   ├── RunCard.tsx     # Карточка запуска
│   ├── RunDetails.tsx  # Выдвижная панель (drawer) с деталями и логами
│   ├── RunsToolbar.tsx # Поиск, фильтры и сортировка
│   ├── Sidebar.tsx     # Боковая панель навигации (скрывается на мобильных)
│   └── StatusBadge.tsx # Бейдж статуса (текст + цвет)
├── App.tsx       # Главный компонент (сборка страницы)
├── App.test.tsx  # Интеграционные тесты
└── index.css     # Глобальные стили и CSS-переменные
```

## ✨ Реализованные требования и бонусы

- **Адаптивность:** интерфейс корректно работает на экранах от `360px` (карточки перестраиваются в колонку, сайдбар скрывается, модалка открывается на весь экран).
- **Доступность и клавиатура:**
  - Реализовано полноценное управление с клавиатуры.
  - Карточки запусков доступны для фокуса (`Tab`) и открываются по `Enter` / `Пробел`.
  - Модальное окно закрывается по `Escape`, при открытии фокус автоматически перемещается внутрь окна.
  - Используются ARIA-атрибуты (скрытые лейблы, `aria-pressed`, `role="status"`).
  - Статусы не полагаются только на цвет (добавлен текст).
- **URL-фильтры (Бонус):** поиск и фильтр статуса синхронизируются с URL (сохраняются при перезагрузке страницы).
- **Сортировка (Бонус):** по дате и длительности.
